# Anettrace v0.8.3

## 主要变化

- 修复全量抓取在 BPF 缓冲区丢事件后提前结束的问题。`--capture-trace --force --duration 30` 现在会继续抓取至指定时长；丢事件不再触发自动停止。
- 同样修复 `--perfetto-events` 导出和环形抓取的丢事件退出行为。环形抓取继续运行，直到用户中断后保存指定时间窗口。
- 丢失的事件数仍写入 Perfetto 元数据，并在终端输出告警。继续抓取无法补回丢失的数据；需要完整事件时，可使用 UID、协议或端口过滤降低采集负载。
- 增加真实丢事件回调与计时退出逻辑的回归测试，覆盖三十秒截止时间、环形窗口、用户中断及普通终端追踪行为。

## 快速使用

```sh
# 在具有 root 权限的设备 shell 中抓取三十秒
./anettrace --capture-trace --force --duration 30 \
  --output /data/local/tmp/network.pftrace --trace-profile full

# 按目标应用的实际 UID 过滤，减少事件量
./anettrace --capture-trace --uid 10187 --duration 30 \
  --output /data/local/tmp/app-network.pftrace --trace-profile full
```

`duration` 从开始采集事件时计时，进程总运行时间还包括 BPF 加载和文件合并。
下载后请核对 `SHA256SUMS`，运行 `--version` 确认版本为 `0.8.3`。
