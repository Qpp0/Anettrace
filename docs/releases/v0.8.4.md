# Anettrace v0.8.4

## 主要变化

- 将 Traffic UI Pre.5 的功能合入正式版本，新增 `--traffic-ui` 显式开启交互式流量概览；直接使用 `--traffic` 继续输出原有逐周期追加的九列表格。
- 新界面展示线程 TID、线程名称、PID、完整本地/远端 IP 和端口，并区分当前速率与“累计接收 / 累计发送”。支持线程明细和进程汇总、窄屏换行及中文操作提示。
- 已采到的空闲线程与端点记录持续保留，显示采样日期时间、最近收发时间和空闲时长，方便对应场景与线程活动。
- 按 `h` 查看目标记录最近 60 次采样的收发量与速率，每次显示采样结束时间和实际间隔。`k` 看更早，`j` 看较新，`h` 返回；`p/f` 切换进程/线程，`q` 退出。
- 总累计使用独立计数器；明细被内核淘汰后仍保留已观察到的记录与累计量，缺失周期显示未知。无法恢复采样间已经淘汰且未曾观察到的数据。
- 保留 v0.8.3 的抓取时长修复：Perfetto 采集遇到 BPF 缓冲区丢事件时，继续运行至指定时长。

## 快速使用

```sh
# 原有界面：持续追加流量表格
./anettrace --traffic --proto tcp --uid 10187 --interval 1

# 新界面：当前速率、累计量与逐次历史
./anettrace --traffic-ui --proto tcp --uid 10187 --interval 1

# 新界面也可以在后台抓取并保存轨迹
./anettrace --traffic-ui --capture-trace --proto tcp --uid 10187 \
  --duration 30 --trace-profile full --output /data/local/tmp/network.pftrace
```

`--traffic-ui` 已包含 `--traffic`，也可同时指定。默认每秒刷新，历史保留最近 60 次采样；改变 `--interval` 会改变覆盖的时间范围，累计记录独立于历史窗口保留。

输出重定向、`TERM=dumb` 或没有可用 ANSI 终端时，自动使用旧表格。`--count` 仍限制周期报告次数，界面切换不会消耗次数。

统计成功的 Socket sendmsg/recvmsg 返回字节，包含 TLS 记录开销及 PEEK 重复读取，不等于网络接口线上流量。明细缓存最多保留 16384 个线程/端点身份和 4096 个进程实例；达到上限会提示，优先保留已有记录。完整说明见[交互式流量概览](https://github.com/ron159/Anettrace/blob/v0.8.4/docs/traffic-overview-experiment.md)。

下载后核对 `SHA256SUMS`，运行 `--version` 确认版本为 `0.8.4`。
